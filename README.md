This app keeps a running tally of accumulated reward points by Robinhood Credit Card and sends a notification when threshold reached in order to optimize returns on cashback.
For example, you can be notified every time you reach 100$ (10,000 points), the default setting.
Android requires giving the app access to all notifications but the app ignores everything except messages from robinhood credit card app that contain the patter "+xx points".
